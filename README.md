# Onboarding agents

Este repositório reúne três aplicações independentes:

- [`onboarding-agent/`](onboarding-agent/README.md): Tutor e Curador com Google ADK.
- [`onboarding-agent-langgraph/`](onboarding-agent-langgraph/README.md): variante experimental em LangGraph.
- [`onboarding-agent-curator/`](onboarding-agent-curator/README.md): Curador isolado que importa PDFs e exporta rascunhos para o agente principal.

Cada pasta tem seu próprio `README.md`, `Makefile` e `pyproject.toml`; configure e instale cada aplicação a partir da respectiva pasta.
